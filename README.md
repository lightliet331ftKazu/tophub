# NOVA TOPUP — Vercel-ready demo

A responsive static gaming top-up storefront concept made with HTML, CSS, and vanilla JavaScript. It includes animated visual effects, searchable game cards, bundle selection, player ID input, a demo cart, and a simulated order review.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**.
4. Build command: leave blank. Output directory: leave blank (static HTML at project root).
5. Deploy.

## Important
This is a front-end educational demo only. Prices and bundles are illustrative sample data. It does not connect to game publishers, deliver credits, collect payment, or store orders. Before operating a real top-up business, use authorized suppliers, verify publisher rules, and integrate a legitimate payment provider and secure backend. Never collect game passwords.
